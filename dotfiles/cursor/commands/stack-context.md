# /stack-context

Establish language/framework context before implementing in an unfamiliar stack.

Follow skill **`stack-context`**: detect the stack, pin the verify loop (format, lint, typecheck, test, build), then distill a short project-local rules file from repo evidence and official guides. Community rule packs (cursor.directory and friends) are prunable draft only.

One pass, then code. For Java formatting, skill `java-coding-style` stays the authority.
