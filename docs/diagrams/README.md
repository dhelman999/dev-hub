# Harness diagrams

Excalidraw boards for the public agentic harness. Open in Cursor (Excalidraw extension) or [excalidraw.com](https://excalidraw.com) (File → Open).

Work, interview, and other personal-project diagrams stay in private `dev-hub-personal\diagrams\`.

| File | Shows |
|------|-------|
| [production-two-loop.excalidraw](production-two-loop.excalidraw) | Outer loop (PRD, spec, tickets) interlocked with the inner per-ticket loop (prime, plan, implement, validate, review, PR) |
| [no-mistakes-soft-gate.excalidraw](no-mistakes-soft-gate.excalidraw) | Zoom of REVIEW: the gate ring, `/grounding`, the capped auto-fix loop, the independent diff reviewer, and ask-you |

Green `/skill` names are real invokes. Yellow slices = new agent or human. Orange labels = model band for that arc. No slice = same chat.
